# 2026-11-03

## 链接解析改为严格路径 + 移动改名自动改写链接

用户判断「索引兜底弄巧成拙」，要尊重文件里写好的路径；并要求文件移动后链接自动更新。

### 1. 删掉四步兜底（src/main/links.ts）

原来是「相对目录 → 库根相对 → 全库唯一文件名 → 按显示文字猜标题」。第四步是罪魁：
`[限流策略](限流策略.md)` 库里没这个文件，靠显示文字命中标题为「限流策略」的
`规则/限流阈值.md`，界面显示成功，掩盖了链接本身写错的事实。

现在只认「相对当前目录」和「`/` 开头算库根」，找不到就 broken。顺带删掉 byName / byTitle
两个查找表和 normTitle，它们只服务于已删除的兜底逻辑。

示例库 22 条链接：严格 16 命中 / 6 失效；保留唯一文件名回退 17/5。只多救 1 条却要保留
猜测，不划算，所以全删。

### 2. 撤回 wiki 支持

用户中途改主意（做完渲染层后说「不用支持 wiki」）。没有留半支持状态：索引侧原本解析
`[[ ]]`，如果只撤渲染层，会变成「AI 看得到关系、人看不到」，违反人机同源。所以
`WIKI_LINK` 正则、`RawEdge.wiki` 等字段、markdown-it 的 `ink_wiki` 规则、`.wiki-link`
样式全部移除。

### 3. 新增 src/main/relink.ts

`LinkIndex` 的边增加 `col`（行内字符偏移），因为同一行可能有多条链接，只靠行号定位会改错。
改写流程：

- 移动前 `snapshotInbound()` 快照入链（移动一完成旧路径就解析不到，那些边会退化成断链）
- 物理 rename
- 按 old→new 映射重算相对路径，保留作者原风格：`./` 前缀、`/` 库根、有没有 `.md`、有没有 URL 编码
- 逐行按 col 精确替换，位置对不上时只在整行唯一出现才敢动，否则记 skip
- 同文件多处改动从右往左替换，避免偏移漂移
- 每批 12 个文件并发

踩坑：`[x](./限流.md)` 移到别的目录时，`posix.relative` 返回 `../归档/限流.md`，
直接拼 `./` 会得到 `./../归档/限流.md`。修成「rel 以 `..` 开头就不加 `./`」。

### 4. 接线与提示（src/main/index.ts）

`moveDocTo` / `moveFolderTo` / `doc:rename` 三个入口接上；文件夹移动时把里面每篇文档
批量放进 moves 映射（引用方自己也可能在移动集合里）。改完 `linkIndex.invalidate()`，
通过 `vault:relinked` 事件告诉渲染层改了几处、影响哪些文件。

渲染层收到后：没打开的文档清缓存，打开且没有未保存内容的重新读回来，有未保存内容的
提示「待手动刷新」（防覆盖）。toast 文案「已更新 N 处链接」。

### 验证

单测脚本（三场景，全部 0 失效）：
- 移动 `规则/限流.md` → `归档/`：`规则/告警.md` 的 `./限流.md` 变 `../归档/限流.md`，
  `运维/502.md` 的 `../规则/限流.md` 变 `../归档/限流.md`，库根写法 `/规则/…` 变 `/归档/…`，
  URL 编码写法保持编码
- 改名：`./限流.md` → `./限流策略.md`
- 移动整个文件夹：内部互链的相对路径保持不变，外部链接跟着变

真机（CDP + 示例库）：移动/改名后 toast 显示「已更新 4 处链接」，编辑区路径实时变成新值；
移回来链接又跟着改回去，双向都成立。点「值班表」提示「「值班表」指向的文件不存在」。
