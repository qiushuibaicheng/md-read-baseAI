# 2026-10-30

## Inkwell：Electron Markdown 阅读器（E:\0_work\markdown）

- 技术栈：electron-vite 2 + React 18 + TypeScript + three.js 0.169 + markdown-it + highlight.js，Electron 锁定 38.8.6。
- 源码 16 个文件 / 约 5100 行：`src/main/index.ts`（窗口/全局热键/文件库/剪贴板监听/托盘/IPC）、`src/preload`（contextBridge API + 类型）、`src/renderer/src`（App 状态编排、Sidebar/Preview/SearchPalette/SettingsDialog/ThreeBackground、lib/markdown.ts、styles.css 设计令牌）、`build/make-icons.js`（纯 Node 生成图标）。
- 关键决策：
  - 数据为本地纯文本 md，笔记库默认 `%USERPROFILE%\Documents\Inkwell`，配置/片段/剪贴板历史在 `%APPDATA%\inkwell\`。
  - 全局热键 Alt+Space，被占用时依次退让 Ctrl+Alt+Space → Alt+M。
  - 窗口 `transparent: true` + 3D 点阵背景；早期"预览区纯黑"的坑是预览容器自带的实色背景盖住了 canvas，改为半透明遮罩后解决。
  - `npm run typecheck` 依赖两份 tsconfig（web/node），Vite 构建不做类型校验，preload 的 AppConfig 曾漏 `autoLaunch` 导致类型不一致，已补。
- 用户最终诉求：**不打包**，只交付源码 + 编译过程。已从 package.json 移除 electron-builder 与其 build 字段（dist/dist:setup 脚本、依赖、build 配置），保留 dev/build/start/typecheck 四个脚本，README 改写为「运行与编译」教程。
- 验证：`npm run typecheck` 通过，`npm run build` 产出 out/main、out/preload、out/renderer，`npm start` 与 `npm run dev` 均能正常起窗口。
- 遗留：`release/win-unpacked/resources/app.asar`（2.8MB）被系统句柄占用无法删除，已 gitignore；%APPDATA%\Inkwell 与 %APPDATA%\inkwell 留有调试时生成的配置。

## 第二轮：富渲染 + 内嵌 AI + 视觉升级

- 新增能力：mermaid / markmap / JSON 三种富块（```mermaid、```markmap、```json 围栏），右侧 AI 面板（Ctrl+J），搜索面板 Tab「问笔记库」，diff 确认改稿 + Ctrl+Z 撤回。
- 关键文件：`src/main/ai.ts`（模型档案、SSE 转发、中断、会话持久化，存 `%APPDATA%\inkwell\models.json` / `sessions.json`）、`src/renderer/src/lib/rich.ts`（水合渲染）、`lib/ai.ts`（system prompt/技能/token 估算/diff 解析）、`components/AiPanel.tsx`、`MessageBody.tsx`、`DiffDialog.tsx`、`ModelsDialog.tsx`。
- 主题体系升级为 `data-theme`（dark/light/system）× `data-accent`（indigo/violet/emerald/amber/rose）双维度。
- 踩坑与修复：
  - markmap 只在初始化时 `fit()` 一次，容器变宽后内容按旧宽度居中 → 右边界裁切。改为 ResizeObserver 监听尺寸 → `mm.fit()` → 再按可见节点真实包围盒做一次平移校正并同步 `svg.__zoom`，d3 拖拽不跳位。
  - markmap 内置样式把字重写成 300，深色下文字发灰；用 `--markmap-font/--markmap-text-color` 等变量覆盖。
  - AI 回答里嵌的 mermaid 在 360px 面板内被压到看不清；改为 `.ai-msg .rich-body > svg { min-width:520px; max-width:none!important }` + 容器横向滚动（mermaid 的 inline `max-width` 必须 `!important` 才压得住）。
  - `.md-body` 类名与 ModelsDialog 的栅格类撞名，导致 AI 回答段落只有 154px 宽，统一改名为 `.msg-body`。
  - styles.css 里曾因重复追加出现多段完全相同的规则块（rich-body / docbar-meta / ai-msg-actions），已去重。
- 验证手段：CDP（`--remote-debugging-port=9222`）跑 `Runtime.evaluate` 量尺寸 + `Page.captureScreenshot` 截图；用本地 8899 假 OpenAI 服务验证流式链路。注意 Windows 125% 缩放下窗口 CSS 视口 = 物理尺寸 / 1.25，`Emulation.setDeviceMetricsOverride` 设得比真实视口大就会截出裁切图。
- README 已补：富渲染章节、AI 助手章节、Ctrl+J / Ctrl+Z / Tab 快捷键、models.json 与 sessions.json 位置、按需分包说明、已知边界。
