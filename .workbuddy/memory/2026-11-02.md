### 排序怎么存的
- `config.order: Record<目录相对路径, 条目相对路径[]>`，文件夹与文档混排；没登记的条目排在后面，按「文件夹优先 + zh 名称」补位。
- 拖拽落点由**坐标**算：文档行上下半 → 插前/插后；文件夹行上 28% / 下 28% → 插前/插后，中间 40% → 移入。**在 drop 事件里重新算一次**（不要读 dragover 存的 state，React 渲染时序会让它为空）。
- 落点用 `.drop-line` 插入线 + 圆点表示；文件夹中部悬浮用 `.is-drop` 高亮。
- `vault:arrange({kind, path, targetDir, index})` 在主进程一次完成「跨目录移动（doc/folder）+ 插入排序表」，避免拖完顺序又被字母序打回。文件夹移动会级联改写 order 的键与值、`openTabs`、`lastDoc`。
- 防呆：不能拖进自己 / 自己的子目录；目标同名会报错。

### 顺手修的
- 渲染层 `config.order` 只有在 `config:changed` 时才更新，而新建/改名/删除只改主进程的 order → 新建的文档掉到列表末尾、改名后也会跳到末尾。加 `notifyConfig()` 在这些位置推送。
- 新建文档/文件夹时 `unshiftOrder` 插到所在目录最前面（符合「刚建完就看得到」）。
- 删除时 `dropFromOrder` 顺带摘掉排序表项，避免无限膨胀。
- `App.tsx` 抽出 `remapPaths(from, to)`：标签/正文缓存/脏标记/待存/pending/active/光标/AI 提案/撤回快照一起搬，移动与改名共用；原来只处理了 tabs 与 contents。

## 文档链接图：把「人点链接跳转」变成「AI 也能用的结构」

问题：AI 读笔记时，`[见规范](./流程/规范.md)` 只是一串字符。它得自己算相对谁、猜对了才能读，猜错就报「文件不存在」然后开始编。
更贵的是反方向——改一篇时不知道谁引用了它。原有实现里连人类侧的跳转也没做（`will-navigate` 一律 preventDefault）。

新增 `src/main/links.ts`（约 550 行），主进程持有单例 `LinkIndex`：
- 解析 `[]()` 与 `[[ ]]`，跳过 fenced code / 行内代码 / front-matter，记录行号、锚点、显示文字
- 消歧顺序：相对当前目录 → 库根相对 → 全库唯一文件名 → 全库唯一标题；多个候选判 **ambiguous 并列出候选**，不猜
- 缓存按 mtime+size 判断是否需要重解析；目录扫描只 stat，不读内容
- `scanVault()` 改为从索引取，去掉了原来「每次调用把所有文件读一遍只为取标题」的浪费

四层能力：
- L1 `read_doc`：正文里的链接就地标注成 `〔库内 路径〕` / `〔断链〕` / `〔歧义：a / b〕`，末尾追加「引用 N 篇 / 被 M 篇引用」+ 一句话摘要 + 失效清单，并明确要求模型不要全读
- L3 system prompt：`<link-graph>` 段带当前文档出入链（≤20 条），发消息前由渲染层调 `linksOf` 生成
- L2 工具：`get_links` / `expand_doc`（邻域摘要，上限 300 篇）/ `find_link_path`（BFS）
- L4 UI：`markdown.ts` 给内部链接加 `data-doc-link` 并去掉 href，`Preview` 事件委托 → `linksResolve` → 跳转 + 按标题文字找锚点；底部 `Backlinks` 折叠条显示引用 / 被引 / 失效；设置页显示篇数、引用数、断链、歧义、耗时，可重建。

## 修链接解析两处 bug + 新增 demo/user-story 示例库

## 编辑器行号 + 断链提示可读性

用户截图反馈两处：点「值班表」时 toast 显示 `%E5%80%BC%E7%8F%AD%E8%A1%A8.md`；源码编辑器没有行号。

1. toast 文案：`data-doc-link` 存的是原始 href（中文已 URL 编码），早先直接把它拼进提示。
   加 `linkLabel(raw, text)`：优先链接显示文字，其次 `decodeURIComponent`，失败回退原文。
   现在显示「库里找不到「值班表」」和「「重试规则」同名多篇，未自动跳转：归档/重试规则.md / 规则/重试规则.md」。
2. 行号：新组件 `components/EditorGutter.tsx`。
   **难点是软换行**——一个逻辑行折成多行后，下面所有行的位置都下移，不能用「行号 × 行高」定位。
   做法：隐藏镜像 div 按 textarea 的宽度/字体/padding 重排一次，读每行 `offsetTop`，据此绝对定位行号；
   只渲染视口 ±3 行；跟随 scroll 用 `translateY(-scrollTop)`，跟随尺寸用 ResizeObserver。
   镜像里的空行要垫 `\u200b`，否则量不出高度。CSS 里 `.editor-mirror` 必须 `box-sizing: border-box` 且 width = `ta.clientWidth`。
   `.editor` 左 padding 从 26 降到 10，给 50px 的行号栏让位。

CDP 验证：31 行文档滚动到 scrollTop=260 后只渲染 24 个行号，折行处（第 14/20/24/25/26 行）全部对齐。
typecheck、build 通过，配置已还原。
